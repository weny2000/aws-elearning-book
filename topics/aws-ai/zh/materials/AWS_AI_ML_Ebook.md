## 第二部分: Foundation Models

### 2.1 模型选择决策矩阵

| 使用场景 | 推荐模型 | 备选模型 | 关键考量 |
|---------|---------|---------|---------|
| **通用对话** | Nova Pro | Claude 3 Sonnet | 成本、延迟 |
| **复杂推理** | Claude 3.5 Sonnet | Claude 3 Opus | 推理能力 |
| **代码生成** | Claude 3.5 Sonnet | Nova Pro | 代码质量 |
| **长文档处理** | Claude 3 (200K) | Nova Pro (300K) | 上下文长度 |
| **低成本高吞吐** | Nova Lite | Nova Micro | 成本优先 |
| **开源/可微调** | Llama 3.3 70B | DeepSeek | 可定制性 |
| **中文优化** | Nova Pro | Claude 3 | 中文表现 |

## 第五部分: Agents

### 5.1 Bedrock Agents vs AgentCore 对比

| 维度 | Bedrock Agents | AgentCore |
|------|---------------|-----------|
| **定位** | 声明式、配置驱动 | 编程式、代码驱动 |
| **学习曲线** | 低（控制台配置） | 中高（SDK 开发） |
| **灵活性** | 中（预置模式） | 高（完全自定义） |
| **开发速度** | 快（小时级） | 中（天级） |
| **适用场景** | 标准工作流、快速原型 | 复杂逻辑、高度定制 |
| **与 KB 集成** | 原生支持 | 通过工具调用 |
| **记忆管理** | 基础会话状态 | 短期+长期记忆 |
| **扩展性** | 自动 | 需手动配置 |

**选择建议**: 
- 快速验证 → Bedrock Agents
- 生产级定制 → AgentCore
